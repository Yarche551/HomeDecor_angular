# Frontend (Angular 22)

Клиентская часть интернет-магазина Home Decor.

## Команды

```bash
npm start        # dev-сервер на http://localhost:4200
npm run build    # production-сборка в dist/frontend
npm run watch    # сборка в режиме watch
```

Адрес API задается в `src/environments/environment.ts`
(и `environment.development.ts` для dev-сборки).

Описание проекта целиком — в `../README.md`.
